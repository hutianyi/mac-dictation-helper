# 默写小程序 / Dictation Helper

一个离线、轻量的 macOS 默写工具：粘贴一组中文词语或英文单词，程序逐个朗读，孩子默写完成后按一个键再进入下一个。

不需要账号、网络连接或 API Key。输入内容只保存在本机。

## 功能

- 支持中文词语、英文单词和中英文混合列表。
- 空格、连续空格、换行、Tab、逗号和分号都会被识别为分隔符。
- 默写时隐藏答案；按空格朗读下一个，按 `R` 重读当前词语。
- 每个词语自动朗读两遍，降低首字发音被截断的概率。
- 每个词语限时30秒；15秒时自动重读并语音提醒，30秒时自动进入下一个。
- 30秒内可随时按 `R` 重读，但不会重置或延长倒计时。
- 界面固定使用清晰的浅色外观，不受 macOS 深色模式影响。
- 可选择随机顺序和朗读速度；结束时会提示“默写结束”。
- 优先使用 macOS 的高音质中文 `Lili` 和英文 `Ava` 声音；未安装时自动使用该语言可用的系统声音。

## 使用

1. 双击 `默写小程序.app`。
2. 粘贴词语列表，例如 `苹果 认真 umbrella wonderful`。
3. 点击“开始默写”。
4. 孩子写完一个词后，按空格进入下一个；需要重听时按 `R`。如果没有操作，程序会在30秒后自动进入下一个词。

输入内容和设置会自动保留在本机。

## 系统要求

- macOS 13 或更高版本。
- 已安装 Apple Command Line Tools（只在自行编译时需要）。
- 建议在“系统设置 → 辅助功能 → 朗读内容”下载高音质的 `Lili`（中文）和 `Ava`（英语）声音；没有也可以正常使用。

## 从源码编译

在终端进入本项目文件夹后运行：

```bash
zsh build.sh
```

生成的应用位于 `build/默写小程序.app`。脚本会根据当前 Mac 的处理器和已安装的 macOS SDK 自动选择编译目标。如果电脑安装了多套 Command Line Tools，可用 `DICTATION_SDK=/完整/SDK/路径 zsh build.sh` 指定 SDK。

## 测试

```bash
zsh test.sh
```
